# 六方法统一验证入口

当前比较CCGDE3、LMOCSO、DGEA三条基线与对应改进版。CC改进沿用V6最终方案，LM与DGEA采用V7最终方案；全部使用同一转子重叠尾流与精确Prim评价后端。

180次正式实验已完成，完整数据位于`../reference_results/confirmation_20261024/`。运行、后台检查、断点续跑和结果重分析的命令见仓库根目录README。

- `protocol.py`：3个算例、10个种子、6种方法的固定配置与顺序。
- `runtime.py`：统一评价器、冻结算法路由及完整检查点写入。
- `worker.py`：后台控制器、缓存准备、串行运行及完成后分析。
- `analysis.py`：统一HV、CPU预算比较、统计检验、几何/前沿/HV核查与图表。
- `checks.py`：轨迹一致性、完整恢复、统计函数和文件写入检查。

算法与模型源文件保持正式实验时的指纹。本目录的`_problem`方法名表示上述最终组合。
